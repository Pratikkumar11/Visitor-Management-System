# Visitor Management System

A web-based **Visitor Management System** developed using **ASP.NET Web Forms, C#, SQL Server, and ADO.NET**. This application simplifies visitor registration, QR-based check-in, receptionist approval, and secure role-based authentication.

---

## Features

- Visitor Registration
- QR Code Generation
- QR-based Visitor Check-in
- Receptionist Approval Workflow
- Role-based Authentication (Admin & Receptionist)
- Visitor Record Management
- Secure Login System

## Installation

1. Clone the repository

```bash
git clone https://github.com/Pratikkumar11/Visitor-Management-System.git
```

2. Open `VMS.sln` in Visual Studio.

3. Restore NuGet packages.

4. Configure the SQL Server database connection string.

5. Build and run the project.
